RajSQL: SQL cheat sheet

      
    

    

      
CREATE TABLE students (id INTEGER, name TEXT, gpa REAL)Create a table. Types: INTEGER, REAL, TEXT (NULL is free-form).

      
INSERT INTO students VALUES (1, 'Raj', 3.9)Insert a row; column list is optional.

      
SELECT name, gpa FROM students WHERE gpa > 3.5 AND major = 'CS'Query with a filter. AND / OR / NOT supported.

      
SELECT * FROM students ORDER BY gpa DESC LIMIT 5Sort and limit results.

      
SELECT COUNT(*), AVG(gpa) FROM studentsAggregates: COUNT, SUM, AVG, MIN, MAX.

      
SELECT s.name, c.title FROM students s JOIN enrollments e ON s.id = e.student_id JOIN courses c ON e.course_id = c.course_idINNER JOIN with ON.

      
UPDATE students SET gpa = 4.0 WHERE id = 1Update matching rows.

      
DELETE FROM students WHERE id = 1Delete matching rows.

      
BEGIN; INSERT …; ROLLBACK;Transactions: BEGIN / COMMIT / ROLLBACK.

      
Every table has an implicit rowid INTEGER primary key: rows are addressable even without a declared key.

      
Deletes are tombstones: removed rows are marked rather than physically rewritten, keeping deletes cheap.

      
WAL gives crash safety: writes go to a write-ahead log and are checkpointed into the main file; after a crash the WAL is replayed on startup, so committed data survives.
